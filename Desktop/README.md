# Desktop

Una experiencia de portafolio presentada como un escritorio digital innovador.

## Descripción

Desktop es una presentación visual del portfolio que simula un entorno de sistema operativo. Su objetivo es ofrecer una primera impresión más memorable e inmersiva, permitiendo explorar proyectos, contacto y contenido relevante desde una interfaz interactiva.

## ¿Para qué sirve?

- presentar el portfolio con una identidad más original
- crear una experiencia visual distinta a una landing page tradicional
- facilitar la navegación por proyectos y perfiles profesionales
- reforzar la imagen de un perfil creativo y técnico

## Público objetivo

- recruiters
- clientes potenciales
- empresas y equipos de producto
- colaboradores interesados en diseño y desarrollo digital

## Stack

- HTML5
- CSS3
- JavaScript
- Fetch API

## Funcionalidades principales

- interfaz tipo escritorio
- ventanas interactivas para proyectos y contacto
- integración con GitHub para mostrar repositorios recientes
- reloj, estado del sistema y animaciones visuales
- estructura narrativa que refuerza la identidad del portfolio
