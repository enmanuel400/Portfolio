# Mercium Shop

Landing page premium para servicios digitales y soluciones comerciales.

## Descripción

Mercium Shop es una vitrina digital diseñada para mostrar servicios, paquetes y soluciones para negocios que buscan mejorar su presencia online y fortalecer su propuesta comercial.

## ¿Para qué sirve?

- presentar servicios en un formato atractivo y claro
- captar leads a través de una experiencia comercial moderna
- ofrecer una propuesta visual premium y orientada a ventas
- mostrar soluciones digitales con un enfoque de conversión

## Público objetivo

- startups
- tiendas y negocios digitales
- pequeñas y medianas empresas
- clientes que necesitan una presencia web más sólida

## Stack

- HTML5
- Tailwind CSS
- JavaScript

## Funcionalidades principales

- hero section con propuesta de valor
- catálogo de servicios con filtros y orden
- carrito interactivo
- cálculo automático del total
- formulario de checkout para generar contacto comercial
