# Vellum

Workspace visual para organizar ideas, notas y contenido personal.

## Descripción

Vellum es un entorno de trabajo pensado para que el usuario pueda mantener ideas, referencias y contenido visual en un mismo lugar con una estética limpia y enfocada.

## ¿Para qué sirve?

- organizar pensamientos y tareas
- guardar contenido visual y referencias
- crear un espacio más ordenado para trabajar
- ofrecer un entorno visual calmado y productivo

## Público objetivo

- creadores de contenido
- estudiantes
- profesionales
- personas que necesitan organizar ideas en un flujo visual

## Stack

- Vite
- Electron
- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Funcionalidades principales

- panel tipo workspace
- gestión visual de notas y referencias
- modo claro y oscuro
- enfoque en productividad y legibilidad
- experiencia enfocada en concentración y organización

## Cómo ejecutarlo

Instalar dependencias:

```bash
npm install
```

Modo desarrollo:

```bash
npm run dev
```

Versión desktop:

```bash
npm run desktop
```

Build:

```bash
npm run build
```

## Resumen

Vellum es una propuesta personal para transformar la organización de ideas y contenido en un espacio visual, atractivo y funcional.
